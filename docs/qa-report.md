# SÉRIN 검수 보고서

아래는 초기 제작 검수 기록입니다. 최신 UI/UX 개선·계산 데모·모바일 Ritual 및 현재 검수 한계는 [종합 개선 보고서](uiux-improvement-report.md)를 참고하세요.

검수일: 2026-11-09 (한국 시간). 로컬 정적 HTML·CSS·Vanilla JavaScript 결과물.

## 실행한 검수

- `npm run check`: 통과. JavaScript 문법, 문서 구조와 파일 경로, DOM 통합 동작.
- 10개 메인 섹션, 단일 h1, 유일한 ID, 20개 이미지 요소의 대체 텍스트·크기 속성 확인.
- 모든 HTML 로컬 리소스·섹션 앵커, 6개 상세창과 5개 FAQ, 저널 본문 3편 확인.
- 로컬 Manrope·Pretendard의 WOFF2 파일 시그니처 확인. 다운로드 중 발견한 Manrope 형식 차이를 올바른 WOFF2로 수정.
- 메뉴 열기·링크 선택 닫기·Escape, 배경 inert 상태, 갤러리 src·선택 상태, 모든 상세창 트리거·닫기·내부 섹션 이동을 DOM 환경에서 확인.
- 원본 15종을 직접 시각 검토. 패키지 색상·형태·워드마크·스틱 구성을 기준 이미지와 비교. 캠페인 상세 사진은 동일 모델 및 패키지를 참조.
- 정적 HTTP 서버 구동 확인. `/`, 두 CSS, JS, 히어로 WebP, Manrope WOFF2 요청의 200 응답 및 Content-Type 확인.
- WebP 19개 총 약 1.9MiB. 히어로 작은 파생본 및 제품 썸네일 생성. 원본 PNG 보존.

## 브라우저 검수 제한

브라우저 연결 호스트를 사용할 수 없었다. Windows Chrome 창을 확인하는 대체 경로에서는 현재 URL을 확신할 수 없어 보안상 Computer Use가 중단되었다. 이후 UI 자동화를 계속하지 않았다.

따라서 실제 브라우저 스크린샷·뷰포트 측정·가로 넘침 측정은 생성하지 않았다. 브라우저 동작이나 레이아웃을 DOM 검수만으로 통과했다고 판단하지 않았다.

## 로컬 최종 확인 순서

1. `npm run dev` 후 `http://127.0.0.1:4173`을 연다.
2. 브라우저 반응형 모드에서 1440·1024·768·390px 및 375px를 확인한다.
3. 히어로의 제품 크롭·타이틀, 제품 갤러리, 원료 표, 질감 분할, 캠페인 모델 크롭, 저널·푸터에 잘림·가로 넘침이 없는지 확인한다.
4. 모바일 메뉴와 Escape·Tab 순서, 모든 제품 이미지 버튼, 제품 상세와 저널 3편, 모달 닫기·포커스 복원, FAQ Enter/Space 동작을 확인한다.
5. OS 또는 브라우저 reduced motion 환경에서 스크롤·등장·hover 애니메이션이 멈추는지 확인한다.

제품 배합·원료 출처·함량·당류·알레르기·섭취 지침 검증, 단일 패키지 아트워크 및 실제 촬영, 실제 사업자·고객지원·정책 정보, 결제·회원·개인정보 처리 기능. 배포 시에는 실제 URL로 Open Graph 절대 주소·canonical 설정 및 공유 미리보기 검수가 필요하다.
