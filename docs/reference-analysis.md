# SÉRIN 레퍼런스 분석 및 디자인 결정

확인일: 2026-11-09 (한국 시간)

## SOOO — 접근하여 확인한 내용

- 메인: https://sooo.kr/
- 브랜드 철학: https://sooo.kr/shopinfo/company.html
- 기술 아카이브: https://sooo.kr/board/gallery/read.html?board_no=8&no=12400

웹 조회 도구로 문서 구조와 텍스트를 확인했다. 시각적 렌더링을 직접 확인한 분석은 아니다.

메인은 상품 구성을 소개한 뒤 기술·브랜드 활동을 담은 아카이브와 브랜드 철학으로 연결한다. ABOUT은 연구의 출발점, 지속성, 본질과 원료 선택의 이유를 짧은 구획으로 설명한다. 기술 아카이브는 문제 상황 → 소재의 역할 → 기술 설명 → 적용 범위로 내용을 확장한다. 상품 정보 밖에도 브랜드의 선택 이유를 탐색할 경로를 제공한다는 점을 참고했다. 해당 사이트에 기재된 기술·효능 주장의 사실 여부를 별도로 검증한 것은 아니다.

SÉRIN에는 철학 → 제품 구성 → 원료 공개표 → 감각·일상 → 저널·FAQ의 이해 흐름으로 재해석했다. 실제 연구나 인증이 없는 가상 브랜드이므로, 연구 수치·효능·인증으로 신뢰를 표현하지 않고 정보의 확정 상태를 명확히 공개하는 태도로 표현했다.

## MONO ARCHIVE — 접근 제한

요청 주소: https://ujin2019-oss.github.io/cafe1/01_mono-archive/index.html

웹 조회 도구에서 접근 오류가 발생했다. 브라우저 연결도 사용할 수 없었으므로 실제 레이아웃·이미지·인터랙션을 분석했다고 주장하지 않는다. 사용자가 제공한 대형 영문 타이포그래피, 패션 에디토리얼, 비대칭 편집과 여백이라는 방향을 디자인 요구사항으로 적용했다.

## SÉRIN의 독립적인 해석

- Quiet Science: 원료 항목별 개발 상태를 펼쳐 보이는 공개표. 임의의 연구 그래프나 검증 수치 없음.
- Modern Wellness: 석회암·리넨·종이·유리와 자연광을 일관되게 사용한 화보.
- 브랜드 워드마크·영문 제목: 로컬 Manrope. 한글: 로컬 Pretendard.
- 색상: 딥 그린·웜 아이보리 중심, 세이지의 섹션 배경과 샴페인 질감 사진으로 보조.
- 편집 리듬: 히어로 오버랩, 비대칭 철학, 제품 갤러리, 원료 공개표, 분할 질감 화보, 시차를 둔 일상·저널, 전체 폭 캠페인, FAQ.
- 브랜드 신뢰: 미확정 성분과 기획 단계의 맛·식감, 가상 가격·구성을 해당 콘텐츠 옆에 표시.
- 버튼: 구현한 섹션이나 실제 상세창으로 연결. 가상 결제·회원·SNS 링크 없음.

패키지 사진의 인쇄는 이미지 생성의 특성상 미세한 글꼴·자간 차이가 남을 수 있다. 기준 이미지를 참조해 색상·형태·구성·브랜드명을 통일했으며, 실물 제품 출시 시에는 단일 패키지 아트워크를 기반으로 다시 제작해야 한다.
