# SÉRIN UI/UX 개선 보고서

검수일: 2026-11-09 · 기존 정적 홈페이지의 UI/UX 개선. 전면 리디자인, 이미지 재생성, 실제 판매 연동은 진행하지 않았습니다.

## 프로젝트 분석

기존 순서는 Hero → Philosophy → Product → Ingredients → Sensory → Ritual → Campaign → Journal → FAQ → Closing이며 그대로 유지했습니다. 푸터는 메인 10개 섹션 이후에 유지했습니다.

| 반응형 | 1250·1100·850·700·374px 및 넓은 화면 1600px 규칙. 일부 모바일 본문 10~13px. |

| 이미지·성능 | WebP·반응형 picture·히어로 우선 로딩·하단 lazy loading·크기 속성. |

## 섹션별 개선

| 영역 | 변경 전 → 변경 후 |
| --- | --- |
| Hero | 모바일의 긴 최소 높이 → 휴대폰에서 `clamp(640px, 100svh − 헤더 높이, 780px)`로 조정. 큰 헤드라인의 두 줄 구성은 유지하고 설명·CTA 간격을 압축했습니다. 작은 영문 보조 문구는 휴대폰에서 숨겨 핵심 카피와 제품을 함께 인지할 공간을 확보했습니다. 기존 이미지·3초 전환·일시정지·모션 감소 동작을 유지했습니다. |
| Brand story | 좁은 들여쓰기와 작은 설명 → 모바일 들여쓰기를 없애고 본문 15px·행간 1.7, 한글 주요 카피 22px로 위계를 정리했습니다. 2단 구성과 비대칭 화보를 유지했습니다. 가치 4개의 제목·설명 간격도 통일했습니다. |
| Product | 분산된 구성·가격·특징 → 제품명, 핵심 설명, 단일 기획 구성, 단가, 수량, 선택 합계, 상세 CTA 순으로 재구성했습니다. 기존 사진+정보 2단/모바일 세로 구조를 유지했습니다. |
| Gallery | 선택 상태가 약한 썸네일 → 선택 테두리와 약한 세이지 배경을 강화하고 `aria-controls`를 연결했습니다. 이미지에는 contain을 적용해 패키지 크롭을 피하도록 했습니다. 기존 이미지 전환과 선택 상태를 유지했습니다. |
| Ingredients | 작은 글씨로 반복되는 미확정 정보 → 제목 15~16px, 설명 14~15px 및 간격을 정리했습니다. 기존 5개 항목을 그대로 유지했으며 원료·함량·당류·출처·알레르기를 임의로 확정하지 않았습니다. |
| Sensory | 큰 사진과 작은 모바일 설명 → 사진은 유지하면서 모바일 메인 높이를 300px로 줄이고, 보조 사진·설명의 비율과 14px 설명·12px 기획 안내를 조정했습니다. 구매 버튼이나 카드 UI는 추가하지 않았습니다. |
| Ritual | 모바일 세로 나열 → 기존 사진 3개를 가로 scroll-snap으로 구성했습니다. PC 3열과 에디토리얼 배치는 유지하고 카드 본문은 14px로 높였습니다. |
| Campaign | 히어로와 동일한 `Beauty, from within.` → `A Ritual, Just for You.` / `일상 속 작은 습관으로, 나를 돌보는 시간.`으로 구분했습니다. 모델·의상·딥그린 배경은 유지하며 모바일 타이틀과 배치 범위를 조정했습니다. |
| Journal | 이미지·하단 링크 위주 → 제목에도 기존 상세 모달 연결을 추가했습니다. PC 3열과 모바일 1열을 유지하며 모바일 이미지 비율을 4:3, 제목 23px·설명 14px로 정리했습니다. 기존 본문을 새로 만들거나 교체하지 않았습니다. |
| FAQ | 작은 질문·답변 → 질문 15~16px, 답변 14~15px, 최소 72px 질문 영역과 열린 질문 강조를 적용했습니다. 네이티브 키보드 동작을 유지하고 `aria-expanded`·답변 연결을 동기화했습니다. |
| Header | 기존 구조 유지. 시그니처는 제품 상세 정보의 `#product-details`, 전체 제품·제품 아이콘은 `#product`로 이동합니다. 고정 헤더·56px 축소·모바일 메뉴를 유지했습니다. |
| Footer | 딥그린 3열 구조 유지. 브랜드·고객지원 설명과 하단 안내를 읽기 쉽게 확대하고 모바일 간격을 조정했습니다. 가상 사업자·연락처를 만들지 않았습니다. |

위 설명은 코드 기준 변경 전후 비교입니다. 실제 브라우저 전후 스크린샷은 제작하지 못했습니다.

## 제품 선택·가격 UX

실제 판매 데이터가 없는 포트폴리오입니다. 따라서 ‘결제 금액’·‘구매 완료’ 대신 **선택 금액(데모)**과 **제품 상세·개발 정보 확인**으로 행동을 명확하게 표시했습니다.

- 구성은 기존의 **20g×30포·1박스** 하나만 제공합니다. 추가 맛·세트·할인·배송비·세금·재고 정보는 만들지 않았습니다.
- 기존 가상 단가 **49,000원**으로 수량과 합계를 계산합니다.
- 1~99박스 입력 범위는 계산 데모의 UI 검증 범위이며 실제 판매 제한이나 재고를 의미하지 않습니다.
- 수량 버튼은 44px 이상, 직접 입력·빈 값·범위 초과·소수 입력을 처리합니다. 잘못된 입력 동안에는 유효한 합계로 오인하지 않도록 ‘수량 확인’을 표시합니다.
- 입력 확정 시 1~99의 정수로 보정하고 변경 내용을 안내합니다.
- CTA는 기존 제품 상세 모달을 엽니다. 장바구니·결제·주문 완료를 가장하지 않습니다.

| 검수 입력 | 결과 |
| --- | --- |
| 1박스 | 49,000원, 감소 버튼 비활성 |
| 2박스 | 98,000원 |
| 3박스 | 147,000원 |
| 4박스 | 196,000원 |
| 99박스 | 4,851,000원, 증가 버튼 비활성 |
| 100 | 입력 중 오류 안내, 확정 시 99로 보정 |
| 0·빈 값 | 입력 오류 안내 또는 확정 시 1로 보정 |
| 1.5 | 입력 중 정수 안내, 확정 시 1로 보정 |
| 단일 구성의 change | 현재 수량·합계를 유지 |

다른 옵션은 실제 데이터가 없어 추가하지 않았습니다. **복수 옵션별 가격 차등은 현재 해당 없음**이며, 실제 옵션 데이터가 준비되면 별도 구현·검증이 필요합니다.

## Ritual 모바일 탐색

700px 이하에서 카드 폭을 86%로 설정해 다음 카드가 일부 보이도록 했습니다. 일정한 16px 간격, 기존 4:5 이미지 비율, CSS scroll-snap과 기본 스크롤을 사용합니다. 별도 라이브러리나 자동 재생은 없습니다.

영역·카드에 키보드 접근성을 부여하고 좌우 방향키와 이전·다음 버튼으로 탐색할 수 있습니다. 실제 스크롤 위치에 맞춰 버튼의 시작·마지막 상태를 갱신합니다. 첫 카드의 포커스 선이 잘리지 않도록 모바일 포커스 위치를 안쪽으로 조정했습니다.

버튼·키보드·스크롤 상태·마지막 카드 이동·모션 감소 시 즉시 이동은 DOM 통합 검수로 확인했습니다. **손가락 관성 스크롤·실제 스냅 위치·마우스 휠·포커스 표시의 화면 결과는 브라우저 검수가 필요합니다.**

## 반응형 검수 범위

`tools/check-responsive.mjs`는 최종 CSS 규칙의 누락·덮어쓰기를 확인합니다. 화면을 렌더링하거나 가로 넘침을 측정하는 도구는 아닙니다.

브라우저 연결 호스트를 사용할 수 없었고, 현재 열려 있는 브라우저의 URL을 확인하는 Windows 도구도 보안상 중단되었습니다. 이를 우회하지 않았습니다. 따라서 실제 화면의 가로 넘침·겹침·얼굴/제품 크롭·첫 화면 제품 노출·터치·네이티브 키보드 동작을 확인했다고 주장하지 않습니다.

## 수행한 검수

`npm run check` 전체 통과:

- 단일 h1, 10개 섹션, 유일한 ID, 로컬 리소스·앵커, 이미지 alt·크기, 폰트 WOFF2.
- 기존 3초 히어로 전환·재생/정지·키보드·스와이프·비활성 슬라이드 접근성.
- 기존 축소 헤더와 모바일 메뉴, 갤러리, 모든 제품·저널·안내 모달.
- 기존 단가와 단일 구성, 수량·합계·범위·오류 보정.
- Ritual 탐색 상태·마지막 카드·방향키·모션 감소.
- FAQ 펼침 상태와 답변 연결.
- 지정 6개 너비의 CSS 구조·본문 최소 크기·주요 조작 영역 조건.

별도 무결성 비교로 **섹션 순서, FAQ 답변 5개, 기존 저널 본문 3편, 모든 이미지 참조와 이미지 바이너리 50개**가 유지된 것을 확인했습니다. 새 이미지는 생성하지 않았습니다.

단색 토큰 기준 대비 계산은 딥그린/아이보리 11.48:1, 일반 보조 본문/아이보리 5.17:1, 푸터 보조 본문/딥그린 7.69:1입니다. 사진 위 텍스트의 위치별 대비 검수를 대체하지 않습니다.

## 모바일 하단 고정 CTA를 추가하지 않은 이유

현재 실제 결제 동작이 없고, 헤더의 제품 아이콘이 항상 제품 영역으로 연결됩니다. 시그니처 메뉴는 선택 정보로 직접 연결하며 히어로·마무리 CTA도 유지했습니다. 여기에 고정 ‘구매’ 버튼을 추가하면 실제 판매로 오인하게 하거나 작은 화면을 더 가릴 수 있어 추가하지 않았습니다.

## 수정·추가 파일

- `index.html`: 제품 구성·수량·합계, Ritual 탐색 마크업, 모델 카피, Journal 제목 링크, 앵커·대체 탐색 관계.
- `css/style.css`: 정보 위계·입력/선택 상태·가격/CTA·본문·FAQ·푸터, CSS 서식과 중복 선언 정리.
- `css/responsive.css`: 모바일 히어로, 제품·원료·질감·Ritual·Journal·모델·푸터 조정.
- `js/main.js`: 수량·합계 검증, Ritual 버튼/키보드/스크롤 상태, FAQ 접근성 상태.
- `tools/check-interactions.mjs`: 제품 계산·Ritual·FAQ 통합 검수 추가.
- `tools/check-responsive.mjs`: 반응형 CSS 규칙 검수 도구 추가.
- `package.json`: 검수 명령에 반응형 규칙 검사 연결.
- `README.md`, `docs/qa-report.md`, 본 보고서: 현재 구현과 검수 한계 기록.

## 남은 확인·운영 전 과제

1. 실제 브라우저에서 지정 6개 화면의 넘침·겹침·제품/얼굴 크롭·히어로 첫 화면·원활한 터치/마우스 탐색을 확인해야 합니다.
2. 네이티브 수량 입력·한국어 스크린리더 읽기·FAQ/모달 포커스 동작도 실제 환경 검수가 필요합니다.
3. 복수 판매 옵션, 실제 가격·영양/원료·알레르기·섭취 지침, 사업자·고객지원·법적 운영 정보는 실제 데이터 확정 후 반영해야 합니다.
4. 실제 주문·결제·회원·배송·개인정보 처리 기능은 제공하지 않습니다.

Git commit 및 push는 진행하지 않았습니다.
